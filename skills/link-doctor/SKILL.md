# 线上链接测活（link-doctor）

> 沉淀自 2026-10 自测清单页 404 排查：本地链接种类正常（kb-upkeep 全绿），
> 线上却有 9 处死链——VitePress 构建后目录没有 index.html。
> 部署面的链接正确性是独立检查维度，本地检查替代不了。

## 用法

```bash
bash scripts/check.sh <页面URL>            # 单页体检：抓取→提取同源链接→逐个探测→死链清单
bash scripts/check.sh <页面URL> --follow   # 顺带对发现的同源 .html 页各体检一层（限 20 页）
```

入口仅 http/https；只探测与入口**同 host** 的链接（公网站点场景，天然规避内网/环回）；
外链不主动请求（反爬误报多、价值低），需要时人工抽检。退出码：有死链为 1，可用于 CI 门禁。

## 探测精度（三个实测踩过的误报坑，脚本已内置处理）

1. **HTML 实体**：属性里 `&amp;` 是合法转义，浏览器会解码回 `&` 再请求——探测前必须
   `unescape`，否则 `AQS&ReentrantLock.html` 这类文件名全部误报 404；
2. **URL 编码**：文件名含空格/全角字符（`Java 并发/`、`补充-强引用 、软引用…`）时
   必须按浏览器行为 percent-encode 后请求，否则 curl 直接 000 误报；
3. **大页截断**：300KB+ 页面跨境拉取可能超时出"壳"（只剩资源链接），脚本对 <20KB
   结果自动重试一次——拿到 7 个 href 的体检结果是抓取问题不是页面问题。

HEAD 优先、451/405/501 降级 GET；3xx 记提示不记死链。

## 死链的常见根因与修复模式

| 形态 | 根因 | 修复位置 |
|---|---|---|
| 目录链接（URL 以 / 结尾）404 | 本地 GitHub 浏览目录有效，静态站构建后目录无 index.html | 构建预处理降级纯文本（MUYI book 的 prepare-src.mjs 已内置该规则）；或源头改为具体文章链接 |
| 具体 .md 链接 404 | 构建白名单没拷贝该文件 / 路径大小写漂移 | prepare-src 白名单或修正源链接 |
| 特殊字符文件名 404 | 文件名含 `&`、空格、全角 | 见上文探测精度——先排除脚本误报，真死再考虑改文件名（重命名代价大，慎动） |
| 资产 404 | 主题/图标路径变更 | 构建配置 |

## 工作流

1. 用户给 URL（或从"某页面链接打不开"的描述定位 URL）→ 跑 check.sh；
2. 死链按形态归因（上表）——先修"探测精度"类误报排除，再动真修复；
3. 修复落在**源头**（构建预处理/源链接），不在部署产物上打补丁；
4. 重新部署后复测同 URL（带 `?v=<时间戳>` 绕 CDN 缓存）至全绿；
5. 若根因是可复用规则（如目录链接降级），沉淀进构建脚本，下次同类自动免疫。
