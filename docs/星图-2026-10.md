## 三、环境备忘（换机/排障速查）

* **网络三通道**：`api.github.com` / `codeload.github.com` 稳（配 gh token 可完成一切含推送——git data API 三步提交）；`github.com` 主站时断时续（整仓 fetch 大仓不可行）；`ssh.github.com:443` 通但 key 未挂账号
* **镜像源**：npm→npmmirror、Python→清华 PyPI、Docker→daemon.json 两活源（`docker.m.daocloud.io` 等）；JDK 走清华 Adoptium
* **Mimosa 门禁**：bash 写文件（heredoc/echo/sed -i）必拦 → Write/Edit；被拦看提示语义，勿硬绕
* **工具链**：uv / pnpm 10.32 / Docker Desktop 29.x / Maven 3.9.11（~/develop）/ JDK8（star-site 编译需 JDK21 容器内构建）
